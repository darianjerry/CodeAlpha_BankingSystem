# C++ Console Banking System 💳

A robust, object-oriented console-based banking application built in C++. This project is designed to simulate core banking operations, featuring secure customer credential management, account handling, and a complete transaction logging and tracking system.

## 🚀 Features

* **Object-Oriented Design:** Built using dedicated C++ classes (`Customer`, `Account`, and `Transaction`) encapsulating necessary attributes and methods.
* **Customer & Credential Management:** Securely handles user creation, profile management, and login credentials.
* **Dynamic Account Operations:** Allows users to check balances, manage multiple accounts, and view detailed account summaries.
* **Transaction History Tracking:** Automatically records deposits, withdrawals, and transfers, allowing users to view recent transactions and inspect specific transaction details.

## 🛠️ Tech Stack
* **Language:** C++
* **Paradigm:** Object-Oriented Programming (OOP)
* **Libraries Used:** `<iostream>`, `<string>`, `<vector>`, `<iomanip>`, etc.

## ⚙️ Getting Started & Compilation

To run this project locally, ensure you have a C++ compiler installed (like GCC/MinGW or Clang).
