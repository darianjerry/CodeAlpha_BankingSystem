# C++ Console Banking & Finance System 💳

A robust, object-oriented console-based banking and personal finance application built in C++. Designed to manage customer profiles, secure login credentials, savings, loans, expenses, daily income, and real-time transaction logging.

## 🚀 Features

* **Object-Oriented Design:** Cleanly structured using dedicated classes (`Customer`, `Account`, and `Transaction`) to encapsulate attributes and methods.
* **Custom Registration & Login:** Allows users to create their own custom profile credentials and securely log in.
* **Complete Financial Tracking:** Handles savings deposits, loan qualification checks, daily wage logging, and categorized expenses.
* **Automated Transaction History:** Automatically records every deposit, loan, and expense, allowing users to view recent transactions and updated balances.
* **Robust Input Validation:** Safeguards against incorrect data types and invalid ranges to prevent program crashes.

## 🛠️ Tech Stack
* **Language:** C++
* **Paradigm:** Object-Oriented Programming (OOP)
* **Key Libraries:** `<iostream>`, `<vector>`, `<iomanip>`, `<string>`, `<ctime>`, `<limits>`
